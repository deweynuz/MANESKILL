# MANESKILL — analysis code

Statistical analysis for **Active versus passive learning for non-technical skills acquisition in medical students under stress: the MANESKILL randomized simulation study** (JMIR Medical Education, manuscript #97016).

A multicentre, three-arm cluster randomised simulation study (16 sessions, 99 undergraduate medical students) comparing no instruction, a didactic lecture and a facilitated reflective discussion on Anaesthetists' Non-Technical Skills (ANTS) performance under stress in a non-clinical escape-room task. The pedagogical kit is on OSF: https://doi.org/10.17605/OSF.IO/NFBDY.

## Contents

| File | Role |
|---|---|
| `maneskill_analysis.ipynb` | The whole pipeline: data preparation, cluster structure (ICC, design effect), mixed models (via R), session-level analyses, sensitivity analyses, Tables 1–3, supplementary tables, all figures, and a final cell that checks the key numbers reported in the manuscript. |
| `lmm_cluster.R` | Linear mixed models with a random intercept for session (lme4/lmerTest, Kenward-Roger degrees of freedom, Tukey-adjusted contrasts via emmeans). Called by the notebook. |
| `outputs/` | Tables (CSV and `all_tables.xlsx`), mixed-model results and figures regenerated by the notebook. |
| `data/` | Not distributed (see below). |
| `requirements.txt` | Python dependencies. |

## Reproducing the analysis

Python ≥ 3.11 and R ≥ 4.1 (`Rscript` on the PATH) are required.

```bash
pip install -r requirements.txt
Rscript -e 'install.packages(c("lme4", "lmerTest", "pbkrtest", "emmeans"))'
jupyter nbconvert --to notebook --execute maneskill_analysis.ipynb --inplace
```

The notebook runs in under a minute. The last cell asserts the numbers reported in the manuscript (effect sizes, confidence intervals, P values, ICCs, session-level counts) and fails if any of them is not reproduced. Versions used for the manuscript: Python 3.11, pandas 3.0, SciPy 1.17, Matplotlib 3.10; R 4.3.3, lme4 1.1-35, emmeans 1.10.

## Data

The raw export (`data/df.xlsx`) contains session dates, hospital rotations, dates of birth and free-text comments that could allow re-identification of students and is therefore **not** included. It is available from the corresponding author upon reasonable request, subject to approval by the ethics committee and to a data-sharing agreement.

Section 1 of the notebook builds a de-identified participant-level dataset, `data/analysis.csv` (one row per participant; sessions recoded `S01`–`S16` in chronological order, session dates recoded to a date index, no characteristics other than year of study and prior experience). When `df.xlsx` is absent the notebook starts from `data/analysis.csv` if present, so the analysis can be reproduced from the de-identified file alone.

## Analysis outline

- **Unit of randomisation and intervention:** session (team of 3–9 students); **unit of ANTS assessment:** participant; **task outcomes in the experimental phase:** session.
- **Primary analysis:** linear mixed model of the phase-2 total ANTS score with arm as fixed effect, the phase-1 score as covariate and a random intercept for session (REML, Kenward-Roger df, Tukey-adjusted pairwise contrasts). The same model is fitted to the change score, to each ANTS domain, to the stress scale, the PDI and the self-rated domains. Sensitivity model: additional random intercept for the session date (site proxy).
- **Session-level sensitivity analysis:** session mean of the ANTS change, Kruskal-Wallis, Mann-Whitney U and exact permutation tests (seed 2026).
- **Session-level task outcomes:** Fisher-Freeman-Halton exact test across arms, pairwise Fisher exact tests, Kruskal-Wallis and Mann-Whitney U tests.
- **Allocation sensitivity analysis:** primary and session-level analyses restricted to the 14 sessions allocated in the unrestricted stage (Supplementary Table 5).
- **Initially planned analysis** (participant-level Mann-Whitney U with Bonferroni correction), as reported in the originally submitted version, kept for transparency (`outputs/supp_participant_level_analysis.csv`; not part of the revised manuscript).

Correspondence between manuscript items and outputs: Table 1 → `outputs/table1.csv`; Table 2 → `outputs/table2.csv`; Table 3 → `outputs/table3_session_level.csv`; Supplementary Table 3 → `outputs/suppTable3_icc_design_effect.csv`; Supplementary Tables 4–5 → `outputs/suppTable4_pdi_items.csv`, `suppTable5_sensitivity_allocation.csv`; Figures 1–2 → `outputs/Figure1_ANTS.*`, `Figure2_task_performance.*`; Supplementary Figures 1 and 4 → `outputs/SuppFigure1_CONSORT.*`, `SuppFigure4_alarm.*`.
